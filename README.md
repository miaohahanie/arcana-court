# 奥术之庭 · ARCANA COURT

一个无侧边栏、无顶栏的沉浸式魔法博客，基于 Three.js 构建，自带**写作工具与一键上传**。

**线上阅读**：https://miaohahanie.github.io/arcana-court/
（线上为纯静态阅读；铭刻室上传需在本地运行 `python serve.py` 后使用）

## 运行（推荐用 serve.py，才能一键上传）

```bash
python serve.py        # 静态服务 + 上传 API，端口 8291
```

访问 http://localhost:8291 。若用其它静态服务器（或直接开 index.html），博客照常可读，但铭刻室会退化为"本地模式"：文章只存进当前浏览器，可在编辑器里"下载备份"手动合并。

## 写文章 · 一键上传（仅管理者）

铭刻室有**咒语门**：入口（导航「笔」/ 归档按钮 / 搜索入口）对读者完全隐藏，直接访问 `#/compose` 也只会看到咒语门，上传接口在服务端校验咒语，无咒语一律 403。

1. 访问 `#/compose`，吟诵管理员咒语（**初始为 `abracadabra`**，在根目录建 `admin.json` 写 `{"key": "你的咒语"}` 即可更改）
2. 填写**标题 / 分类（可选已有或新建）/ 日期 / 符印 / slug**——日期自动换算成月相，字数与咒读时长实时统计，草稿自动保存
3. 正文用咒文速记（Markdown 子集）：`## 标题` · `> 引文` · `- 列表` · `---` 分隔 · 三个反引号代码块（自动高亮）· `**粗**` · `` `码` ``，右侧实时显影
4. 点 **「✦ 上传卷轴」** → 文章写入磁盘的 `posts.user.js`，自动跳转到新文章，首页卡片、归档、标签、搜索、前后章全部可见
5. 写完点 **「封印铭刻室」** 退出管理者模式；咒语在本浏览器记住，换浏览器需重新吟诵

数据分三层：`posts.js`（手写卷轴）+ `posts.user.json`/`posts.user.js`（铭刻室上传，serve.py 维护）+ 浏览器本地（静态模式兜底），按 slug 去重合并。

## 博客功能

- **哈希路由**：`#/post/<slug>` 可直达可分享，前进/后退可用；`#/archive` 归档、`#/tag/<标签>` 筛选、`#/about` 关于、`#/compose` 铭刻室，未知路由落入 404「迷失星海」
- **阅读页**：完整排版、代码高亮、右下符环变阅读进度、上一篇/下一篇、「注入魔力」点赞
- **留言刻印**：每卷评论存 localStorage，带种子刻印
- **符印真名**：场景中七枚符印，悬浮显露真名，点击直达对应文章；◈ 印触发「显露真实」
- **探寻仪式**：点击中央法球或按 `/`，键入咒语实时搜文章/归档/铭刻室，Enter 直达
- **滚动**：镜头沉入奥术法阵，终局法阵撑满背景

## 文件

- `serve.py` — 本地服务器（静态 + 上传/验证 API），**用这个启动**
- `admin.json` — （可选）写 `{"key": "你的咒语"}` 更改管理员咒语
- `index.html` — 首页结构
- `posts.js` — 手写卷轴数据
- `posts.user.json` / `posts.user.js` — 铭刻室上传的卷轴（前者是数据源，后者自动生成）
- `main.js` — Three.js 场景 + 路由 + 页面渲染 + 铭刻室 + 全部交互
- `style.css` — 紫色魔法视觉体系
- `rss.xml` — 静态 RSS（新文章后需手动同步）
